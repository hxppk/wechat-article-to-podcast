# Change: 新增播放详情页与分享/原文/快进后退

## Why
现有播放器仅支持基础播放与列表管理，缺少对内容摘要、原文入口和可分享链接的支持，用户无法快速确认内容与分享传播。

## What Changes
- 增加底部抽屉式播放详情页，展示标题、账号、简介与播放信息
- 详情页右上角增加分享按钮，生成 `/?podcast=<id>` 并复制
- 增加查看原文入口，跳转 `sourceUrl`
- 增加快退 15s、快进 30s 控制与 UI 细节优化
- 支持通过分享链接进入并直接打开详情页（默认不自动播放）

## Impact
- 影响前端页面结构、样式与交互逻辑
- 依赖现有播客元数据字段 `sourceUrl` 与接口返回
- 不引入新后端服务，仅需确认 API 输出字段完整
